
# Persian SMS Spam Detection using Hybrid Deep Learning and Machine Learning

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Paper 1](https://img.shields.io/badge/Paper-IJWR-blue)](https://ijwr.usc.ac.ir/article_155394.html)
[![Paper 2](https://img.shields.io/badge/Paper-IEEE%20Xplore-blue)](https://ieeexplore.ieee.org/document/9786238)

Persian-language SMS spam detection model that combines **Convolutional Neural Networks (CNN)**, **Long Short-Term Memory (LSTM)** networks for feature extraction, and **Support Vector Machine (SVM)** for final classification.

Achieves **97.7% accuracy** on a curated Persian SMS dataset — outperforming traditional machine learning baselines and pure deep learning approaches.

## Dataset

- Custom-collected Persian SMS dataset (spam + ham)
- Preprocessed using Persian-specific text normalization, stop-word removal, and stemming
- Available upon reasonable request (contact authors or open an issue)
