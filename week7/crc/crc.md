## انگیزه و کاربرد CRC

CRC (Cyclic Redundancy Check) یکی از مشهورترین روش‌های **تشخیص خطا** در شبکه‌های مخابراتی و لایه پیوند داده است.  
کاربردها:

- پروتکل‌های لایه ۲ مثل Ethernet  
- سیستم‌های ذخیره‌سازی (HDD/SSD)  
- CAN Bus  
- بسته‌های شبکه و وایرلس  

فرستنده داده را طوری کدگذاری می‌کند که **باقی‌مانده تقسیم آن بر چندجمله‌ای مولد صفر شود**؛ گیرنده دوباره تقسیم را انجام می‌دهد.  
اگر باقی‌مانده صفر نبود، یعنی خطا رخ داده است.

---

## ایده‌ی شهودی CRC

CRC داده را به عنوان یک **عدد باینری خیلی بزرگ** در نظر می‌گیرد و آن را در حساب دودویی مد ۲ بر یک **چندجمله‌ای مولد (Generator Polynomial)** تقسیم می‌کند.

> جمع و تفریق در مد ۲ انجام می‌شود ⇒ معادل XOR است.

---

## مدل ریاضی CRC (حساب دودویی مدولوی 2)

### نمایش باینری به صورت چندجمله‌ای

مثال:

رشته باینری:

```

110101

```

چندجمله‌ای معادل:

\[
x^5 + x^4 + x^2 + 1
\]

### قوانین حسابی:

- `1 + 1 = 0`
- `1 + 0 = 1`
- `0 + 0 = 0`

عمل XOR دقیقاً همین رفتار را دارد.

## الگوریتم تولید CRC در فرستنده

فرض کنید:

- داده = `D`
- چندجمله‌ای مولد = `G`
- درجهٔ چندجمله‌ای = `r`  
  (پس طول G برابر `r + 1` بیت است)

### مراحل:

1. الحاق `r` بیت صفر به انتهای داده:  
```

D' = D << r

```
2. تقسیم دودویی `D'` بر `G` و محاسبه باقی‌مانده.
3. باقی‌مانده طولی برابر `r` بیت دارد.
4. اضافه‌کردن باقی‌مانده به انتهای D → خروجی نهایی (FCS).

---

## الگوریتم بررسی CRC در گیرنده

گیرنده:

1. کل فریم (داده + CRC) را دریافت می‌کند.
2. آن را بر همان چندجمله‌ای `G` تقسیم می‌کند.
3. اگر باقی‌مانده = 0 → فریم سالم  
اگر ≠ 0 → خطا رخ داده است.

---

## مثال کامل مرحله‌به‌مرحله

فرض کنید:

- داده:
```

1101011011

```
- چندجمله‌ای مولد:
```

10011

```
- درجه = 4 → باید ۴ صفر اضافه کنیم.

### مرحله 1: الحاق صفرها

```

1101011011 0000

```

### مرحله 2: تقسیم دودویی (XOR-based)

تقسیم به صورت تکراری انجام می‌شود:  
در هر مرحله اگر بیت شروع = 1 باشد، تقسیم‌کننده را XOR می‌کنیم و جلو می‌رویم.

نمونه‌ای از یک مرحله XOR:

```

11010
10011
-----

01001

```

بعد از کامل شدن تقسیم، باقی‌مانده نهایی مثلاً:

```

1010

```

### مرحله 3: CRC نهایی = 1010

### خروجی فریم:

```

1101011011 1010

````

## چندجمله‌ای‌های معروف CRC

| نام | چندجمله‌ای | طول CRC | توضیح |
|----|------------|---------|-------|
| CRC-8 | `100000111` | 8 بیت | سنسورها و IoT |
| CRC-10 | `11000110101` | 10 بیت | مخابرات |
| CRC-16-IBM | `11000000000000101` | 16 بیت | مودم‌ها، USB |
| CRC-32 | `100000100110000010001110110110111` | 32 بیت | Ethernet, ZIP |

## شبه‌کد و پیاده‌سازی نمونه

### شبه‌کد ساده CRC:

```pseudo
function crc(data, generator):
    r = len(generator) - 1
    data = data + "0" * r

    while there is at least r+1 bits left:
        if leftmost bit is 1:
            XOR data segment with generator
        shift left by 1 bit

    return last r bits
````

### پیاده‌سازی نمونه پایتون:

```python
def crc(data, generator):
    r = len(generator) - 1
    data = data + "0" * r
    data = list(data)

    gen = list(generator)

    for i in range(len(data) - r):
        if data[i] == '1':
            for j in range(len(gen)):
                data[i+j] = '0' if data[i+j] == gen[j] else '1'

    return ''.join(data[-r:])
```

## مزایا و محدودیت‌های CRC

### ✔ مزایا

* تشخیص عالی خطاهای burst
* پیاده‌سازی بسیار سریع (در سخت‌افزار و نرم‌افزار)
* ساده و سبک

### ✖ محدودیت‌ها

* خطا را اصلاح نمی‌کند
* انتخاب چندجمله‌ای مناسب اهمیت زیادی دارد
* در برابر حملات عمدی امنیتی مقاوم نیست

## جمع‌بندی

CRC یکی از قوی‌ترین و پرکاربردترین روش‌های **تشخیص خطا** است که بر پایه‌ی تقسیم چندجمله‌ای در مدولوی ۲ انجام می‌شود. در شبکه‌های کامپیوتری، اترنت، مخابرات و سیستم‌های ذخیره‌سازی تقریباً همه‌جا استفاده می‌شود.
