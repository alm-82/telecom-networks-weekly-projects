# کدهای رید-سولومون (Reed-Solomon Codes)


---

## ۱. مقدمه و اهمیت تاریخی

کدهای رید-سولومون در سال ۱۹۶۰ توسط **ایروینگ رید** و **گاستاو سولومون** در MIT معرفی شد.  
امروزه در همه جا هستند:

| کاربرد واقعی                          | نوع RS استفاده‌شده               |
|---------------------------------------|-----------------------------------|
| دیسک‌های فشرده (CD)                  | RS(255,223) با تکه‌بندی            |
| دی‌وی‌دی (DVD)                        | RS(208,192) × RS(182,172)         |
| کدهای QR                             | RS(255, k) با k متغیر            |
| ارتباطات فضایی (NASA, ESA)           | RS(255,223) + درهم‌نهی             |
| DVB-T, DVB-S, WiMAX                   | RS(204,188)                       |
| RAID-6, Ceph, Hadoop Erasure Coding  | RS(14,10), RS(16,10) و ...        |
| Blu-ray                               | RS با LDC + BIS                   |

> نکته کلیدی: رید-سولومون تنها کد عملی است که به **حد سینگلتون (Singleton Bound)** می‌رسد → **MDS Code**

## ۲. پایه ریاضیاتی – میدان گالوا GF(2⁸)

- کار روی میدان محدود **GF(2⁸) = GF(256)** (معمولاً با چندجمله‌ای اولیه `0x11D`)
- هر سمبل = یک بایت (۸ بیت) → ۲۵۵ مقدار ممکن + صفر
- عملیات: جمع = XOR، ضرب = ضرب گالوا (با شیفت و XOR)

### پارامترهای کد RS(n,k)
- n ≤ 255 → طول کدورد (تعداد سمبل)
- k → تعداد سمبل داده
- t = ⌊(n−k)/2⌋ → حداکثر خطای قابل تصحیح
- حداقل فاصله همینگ: **d = n − k + 1 = 2t + 1**

> حد سینگلتون: d ≤ n − k + 1 → رید-سولومون **بهینه** است!

---

## ۳. ساختار کد سیستماتیک

پیام k سمبل → m(x)  
چندجمله‌ای مولد g(x) درجه ۲t با ۲t ریشه متوالی α⁰, α¹, ..., α^{2t−1}

پیوستن ۲t سمبل پریتی → c(x) = m(x) · x^{2t} + r(x)  
که در آن r(x) = −(m(x) · x^{2t} mod g(x))

در گیرنده: محاسبه ۲t سندرم → حل سیستم برای یافتن موقعیت و مقدار خطاها

## ۴. الگوریتم‌های دیکدینگ معروف

| الگوریتم                  | پیچیدگی               | کاربرد                     |
|---------------------------|-----------------------|----------------------------|
| Peterson–Gorenstein–Zierler | O(t³)                | آموزشی                     |
| Berlekamp–Massey          | O(t²)                 | عملی (کتابخانه‌های مدرن)  |
| Euclidean Algorithm       | O(t²)                 | بسیار رایج                 |
| Forney (Error Values)     | O(t)                  | محاسبه مقدار خطا           |

امروزه: **Berlekamp–Massey + Forney** استاندارد صنعتی است.

---

## ۵. قدرت تصحیح خطا (اثبات‌شده)

| تعداد خطاهای واقعی (v) | رفتار دکودر                     |
|-------------------------|----------------------------------|
| v ≤ t                   | همیشه تصحیح کامل                 |
| v = t + 1               | تشخیص خطا (اما تصحیح نه)        |
| v > t                   | ممکن است تصحیح اشتباه کند        |

همچنین قابلیت **Erasure Correction** دارد:  
حداکثر ۲t erasure یا ترکیب v خطا + e erasure که v + e ≤ 2t

## ۷. پیاده‌سازی عملی در پایتون (با کتابخانه reedsolo)

```python
from reedsolo import RSCodec
rs = RSCodec(10)          # ۲t = ۱۰ → t = ۵ خطا قابل تصحیح
msg = b"Hello Reed-Solomon!"
enc = rs.encode(msg)      # طول = len(msg) + 10
corrupted = bytearray(enc)
corrupted[5] = 123        # خطا عمدی
corrupted[8] = 456
decoded = rs.decode(corrupted)[0]
print(decoded == msg)     # True → تصحیح شد!
